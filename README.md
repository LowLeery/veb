# veb

A web framework project for the [V programming language](https://vlang.io).

**Repository:** https://github.com/LowLeery/veb

## Overview

veb provides a modular codebase for building web applications with V.

The repository currently includes:

- HTTP server and routing components
- Middleware support
- Request and response helpers
- JSON utilities
- Template rendering
- Validation utilities
- Configuration helpers
- SQLite database helpers
