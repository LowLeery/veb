veb

A web framework project for the V programming language.

veb is an open-source project exploring web application development with V.

Components

  • HTTP server and routing
  • Middleware
  • JSON utilities
  • Templates
  • Validation
  • Configuration and database helpers

Installation

v install LowLeery.veb

Use this command after the VPM package identity has been updated.
